# MaschMac
Macro to speedrun Ms. Mascherin's Student Safety Contract

main is the original, clicks through links individually. slower, prone to bugs

main2 is the new and improved one. Pastes link directly into bar after submit. No bugs seen so far. perfect.

# How to Use
Works on Macbook air 13" on Dia browser. prolly wont work well on other things

Starts by solving quiz, but dont have to be on quiz page to begin.
Then submits at bottom.
after it confirms the submitting. extra clicks accounts for if any missed questions
(submit button is in diff location depending how many misses)

 after, either finds way back to quiz page(Version Marko-1) or pastes link to Quiz page (v. Marko-2)

Starts quiz again and repeats forever.
